description: Validate the current implementation before reporting completion. Use when a coding task is ready for final verification.
---

Review the current git diff and repository status.

Run the relevant test, lint, build, and validation commands that already belong to the project.

For web-facing changes, verify the running application when browser tooling is available.

Check for:
- failing tests;
- unintended files;
- secrets or machine-specific data;
- temporary artifacts that should be cleaned;
- unsupported completion claims.

Do not make unrelated changes.

Finish with factual evidence: commands run, results observed, and any remaining limitations.
